# Aplikasi Perbaikan

Aplikasi kasir ini berisi logika yang sudah diperbaiki: diskon otomatis 10%, kuantitas wajib positif, dan kembalian dihitung dari total setelah diskon.

Jalankan `Jalankan_Aplikasi.bat`. Dengan qty `2`, harga `60000`, diskon kosong, dan pembayaran `120000`, aplikasi menampilkan diskon `Rp12.000` serta kembalian `Rp12.000`.
